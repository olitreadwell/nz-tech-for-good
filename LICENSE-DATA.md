# Data licence: CC BY-SA 4.0

The Creative Commons Attribution-ShareAlike 4.0 International License (CC): a public licence for shared data. The directory data in this repository uses that licence. People can share and adapt the data if they give credit and share alike. This is the `CC BY-SA 4.0` licence. It covers `data/entries/`, `data/entry.template.yaml`, and the generated `GUIDE.md`.

This is separate from the [MIT licence](LICENSE) that covers the code, such as scripts, schema, and test gate configuration. The MIT licence (MIT): a short software licence that lets people use, copy, change, and share code.

Data and code use different licences. The Creative Commons licence is built for factual and creative datasets. It requires attribution plus share-alike reuse. The MIT licence is built for software.

## What this means

You are free to:

- **Share**: copy and redistribute the data in any medium or format.
- **Adapt**: remix, transform, and build upon the data, for any purpose, even commercially.

Under the following terms:

- **Attribution**: you must give appropriate credit to the [NZ Tech-for-Good](https://github.com/olitreadwell/nz-tech-for-good) project, link to the licence, and indicate if changes were made.
- **ShareAlike**: if you remix, transform, or build upon the data, you must distribute your contributions under the same CC BY-SA 4.0 licence.
