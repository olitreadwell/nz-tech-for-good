# How entries are chosen

This directory lists Aotearoa New Zealand organisations, projects, and
networks that use technology for public good. Not every NZ tech group
qualifies. This page explains the boundary.

## In scope

An entry belongs here if ALL of the following are true:

1. **New Zealand-based.** The organisation operates primarily in Aotearoa
   New Zealand. International orgs with a small NZ presence are generally
   out, unless their NZ work is substantial and independently verifiable.

2. **Tech-for-good.** Technology is central to what they do ; not incidental.
   "Technology" here includes software, data, digital platforms, hardware,
   and applied research. "For good" means the primary mission is public
   benefit: not-for-profit, government, community-led, or mission-led.
   Purely commercial products don't qualify, even if they're useful.

3. **Verifiable.** Every field in the entry must be confirmed against a
   live, public source. If a fact can't be verified, it's left empty.
   Never invent or guess.

4. **Active.** The organisation is currently operating. Defunct or inactive
   groups can be listed with `status: inactive` and a note explaining why.

## Out of scope

- Purely commercial products with no public-benefit mission
- Individual consultants or freelancers (unless they run a public-good
  project or network)
- International organisations with no substantial NZ presence
- Groups that existed briefly and left no trace
- Unverifiable claims or self-reported descriptions without a live source

## Examples

| In scope | Why |
|----------|-----|
| data.govt.nz | Government open data platform, technology is the product, public benefit |
| Digital Aotearoa Collective | Community network using tech for social change, volunteer-run |
| Figure.NZ | Charity turning data into public charts, tech-first mission |
| Karo | Māori-owned health software company, mission-led, serves primary care |

| Out of scope | Why |
|-------------|-----|
| A commercial SaaS startup | No public-benefit mission |
| An individual's blog about tech | Not an organisation or network |
| A global NGO with a tiny NZ chapter | Not primarily NZ-based |
| A defunct meetup group from 2018 | Not active |

## How to suggest an entry

If you know a group that fits the scope:

1. **Check it's not already listed** ; browse [GUIDE.md](../GUIDE.md) or
   search the [live site](https://olitreadwell.github.io/nz-tech-for-good/).
2. **Verify it's active** ; check the website resolves and the org is
   still operating.
3. **Open an issue** using the [add-entry template](../../issues/new?template=add-entry.yml)
   or open a pull request following [CONTRIBUTING.md](../CONTRIBUTING.md).

## Edge cases

If you're unsure whether something belongs, open an issue and ask. The
directory is community-maintained ; the scope evolves with consensus.
When in doubt, err on the side of inclusion: it's easier to remove an
entry later than to recover one that was never added.
