# User personas

Six people use the NZ Tech-for-Good directory. This page lists their needs, journeys, and pain points.

## 1. Job Seeker: Tāne

- **Who**: Early-career developer looking for mission-led work in New Zealand.
- **Needs**: Find groups that are hiring. Filter by region and domain. See what kinds of roles exist in tech-for-good.
- **Journey**: Land on the home page. Filter the directory by region (Wellington). Look for groups with careers pages. Open several career links. Bookmark interesting groups.
- **Pain points**: Cannot filter by hiring or by groups that take helpers. Most entries do not list a careers page. Cannot save or bookmark entries.
- **Features needed**: A filter for hiring and helpers. A clear careers link. Saved entries in local storage. A list of groups hiring near you.

## 2. Volunteer: Māia

- **Who**: Data scientist who wants to volunteer skills for a cause.
- **Needs**: Find groups that take volunteers. Match skills to tasks. Learn what kind of help each group needs.
- **Journey**: Search for "data" or browse by domain. Look for groups marked as taking helpers. Visit websites to find volunteer pages. Contact groups.
- **Pain points**: No filter by skill. The helper field is often empty. No detail on what kind of helpers are needed. Cannot filter by remote or in person.
- **Features needed**: A volunteer match search. A list of skills. Labels for helper types. A remote or in-person label.

## 3. Researcher: Dr. Aroha

- **Who**: Academic who studies the New Zealand civic tech sector for a paper.
- **Needs**: Full data. Export tools. Citation details. A clear method. A summary of each domain.
- **Journey**: Browse by domain. Read the stats page. Export data as CSV or JSON. Cite the directory in a paper. Reference the method.
- **Pain points**: Data exports work but need docs. No citation tool. The method is spread across many docs. Cannot filter by founding year or other fields.
- **Features needed**: A citation tool. A method page. Better data exports. Filters for set fields such as founding year. Docs for the data feed.

## 4. Group Representative: Hana

- **Who**: Runs a small climate-tech nonprofit. Wants the group listed and wants to find peer groups.
- **Needs**: Add or edit the group entry. See similar groups. Understand the sector. Connect with peers.
- **Journey**: Use "Suggest an entry". Check the directory for similar groups. Browse the ecosystem page. Look at domain links. Follow links to peer groups.
- **Pain points**: Entry edits need a GitHub pull request, which is a barrier. No "similar groups" advice. The ecosystem page is one graph and hard to use. No way to claim or verify a group entry.
- **Features needed**: A "similar groups" box on entry pages. An "also in this domain" section (it exists). A claimed or verified badge. Easier entry edits.

## 5. Funder: James

- **Who**: Impact investor who checks the New Zealand tech-for-good sector for grants.
- **Needs**: A view of the sector. Group size and maturity. Domain coverage. Gaps in the sector.
- **Journey**: Read the stats page. Browse by domain. Look at entry founding years and notes. Find gaps. Download data for analysis.
- **Pain points**: No group size or staff data. No funding data. Cannot see group maturity. Many founding years are missing. The stats page could show more.
- **Features needed**: Maturity labels and a founding decade filter. Group size and staff count. A domain gap report. Stats for funders.

## 6. Curious Citizen: Sam

- **Who**: New to New Zealand. Has heard of tech-for-good and wants to learn what exists and how to get involved.
- **Needs**: A simple start. Guided paths. Clear next steps. No overload.
- **Journey**: Land on the home page. See stats and "recently added". Click "Get involved". Browse groups. Maybe look at a domain.
- **Pain points**: The home page works but does not feel welcoming. No "start here" path for first-time visitors. Some domain names use jargon. The get-involved page could be more easy to find. No guided tour.
- **Features needed**: A "start here" section. A guided tour. A clearer get-involved link. Domain notes (they exist). A "new to New Zealand tech-for-good?" section.
